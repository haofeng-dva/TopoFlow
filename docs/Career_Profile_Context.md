# 求职项目与实习背景

更新日期：2026-07-26

## 中文在线实习

### 项目定位

中文在线短剧 AI 全自动生产系统，方向为 AI 应用、技术方案、内容生产自动化与工具链开发。

项目基于已上市的 FlareFlow 软件，以及技术部门现有 `shortdrama-cli`、业务 API 和 AI 生成能力，进行能力串联、流程优化和上层控制开发，而非从零训练底层生成模型。

### 个人工作与角色

- 使用 Vibe Coding 方式参与全栈开发、系统串联和优化。
- 阅读并梳理 Python CLI、接口文档及服务端调用链。
- 区分真实 API、Mock 命令和待接入能力，建立能力矩阵。
- 设计生产控制层、结构化任务、工作流和质量闭环。
- 串联剧本拆解、资产提取、图片、视频、TTS 和任务查询能力。
- 设计状态机、异步轮询、失败定位、有限重试、模型降级和人工异常队列。
- 设计规则检查、轻量模型、多模态评审和人工兜底组成的分级质量闸门。
- 规划提示词、模型参数、参考素材、质量评分、失败记录、人工修改和成本数据的追溯体系。
- 输出架构梳理、技术方案、图解材料和阶段实施计划。

### 技术关键词

Python、Typer、Pydantic、JSON Schema、REST API、OpenAI Compatible API、HTTP 鉴权、异步任务、状态机、任务队列、DAG、有限重试、Git、PowerShell、全栈开发、LLM 任务规划、多模态质量评审、Prompt 版本管理、Embedding、OpenCV、FFmpeg、TTS、图像生成、视频生成。

### 表述边界

已完成：系统和接口梳理、能力矩阵、总体架构、质量闭环方案、实施路线及汇报材料，并基于 FlareFlow 进行串联和优化开发。

方案或调研：ControlNet、LoRA、轻量缺陷分类器、完整离线训练闭环等没有实际实现证据的部分，不表述为已独立开发或已上线。

不得表述为：从零开发 FlareFlow、独立训练基础模型、独立完成整套已上线生产系统，或拥有未经验证的生产指标。

## TopoFlow 项目

自动化 3D 游戏资产处理与质量控制工具链，覆盖模型诊断、重拓扑、UV、烘焙、质量门禁、资源打包和团结引擎导入验证，并提供 CLI、FastAPI、Gradio、队列、缓存、任务状态和规则数据能力。

## 求职定位

- AIGC 应用研发与 AI 工具链
- 游戏客户端工具开发
- AI 后端与工作流平台开发
- 游戏 AI Agent 工程
- 内容生产自动化
- 游戏构建和测试开发
- 多模态内容质量评估
- 技术方案、技术策划和技术产品

核心定位：能够连接内容业务、AI 模型和工程系统，基于现有成熟能力完成全栈串联、自动化编排、质量闭环、失败恢复与工程优化。
