# TopoFlow Agent Instructions

## Installation Policy

- Install project-related third-party applications, SDKs, model weights, caches, and large dependencies on the D drive by default.
- Preferred tool root: `D:\TopoFlow\tools`; preferred shared SDK root: `D:\DevTools`.
- Keep generated assets, downloads, temporary model data, and package caches off the C drive whenever the installer or tool supports a custom path.
- For automated web downloads, prefer files below 20 MB, avoid large sample packs, and save directly under a project folder on D drive.
- Ask before downloading any individual file above 100 MB or any collection expected to exceed 500 MB.
- Do not move Windows-managed components or existing user profiles merely to satisfy this preference.
- Before installing exceptionally large software such as Unreal Engine, confirm the exact version, components, and expected disk usage with the user.
